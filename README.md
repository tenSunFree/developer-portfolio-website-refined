## Tech Stack

- Next.js  
  React framework for building SEO-friendly web applications with static generation and production-ready frontend capabilities
- React  
  Component-based UI library for building dynamic, reusable, and interactive user interfaces
- TypeScript  
  Statically typed JavaScript superset for improving maintainability, type safety, and developer productivity
- Sass (SCSS)  
  Styling solution for building scalable and maintainable UI styles with reusable structure and theme consistency
- Framer Motion  
  React animation library for smooth transitions and polished user interactions
- Jest + Testing Library  
  Testing solution for validating component behavior and improving application reliability
